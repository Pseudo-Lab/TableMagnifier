# Domain Vocab Policy

canonical real-data benchmark는 공개 원자료 복제가 아니라 현실형 합성 데이터다. 어휘는 실제 업무 표처럼 들리되, 특정 회사나 민감 데이터에 묶이지 않아야 한다.

## 권장 어휘 축

- 기간: `1월`, `2월`, `3월`, `주간`, `월간`
- 채널: `온라인`, `오프라인`, `도매`, `제휴`
- 재고: `가용재고`, `반품`, `조정`, `보류`
- 보고: `지역`, `팀`, `제품군`, `소계`, `합계`
- 운영: `집행`, `기준`, `예외`, `범위`, `메모`

## 피해야 할 것

- 과도한 비즈니스 jargon
- 영어 혼용이 없으면 이해되는 부분의 불필요한 영어
- 문제 구조를 직접 설명하는 메타 단어
- 사람 이름, 고객명, 실제 회사명

## 숫자 원칙

- seed 기반 deterministic 값만 사용한다.
- 값은 현실형 범위를 유지하되 너무 큰 숫자나 긴 단위를 남발하지 않는다.
- 값 자체보다 표 구조와 범위 판단이 정답을 좌우하도록 설계한다.
